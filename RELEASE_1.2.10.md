# Inviter Studio 1.2.10

Исправлена проверка готовности кампании личных сообщений. Если среди выбранных аккаунтов есть ограниченный, отключённый или временно недоступный аккаунт, это отображается в диагностике, но запуск продолжается, когда остаётся хотя бы один пригодный аккаунт. Если пригодных аккаунтов нет для одной из непустых очередей, диагностика объясняет, какая очередь остановлена.

Лимит первых сообщений не блокирует ожидающие вторые сообщения после ответа получателя. Для двух типов отправки отдельно проверяется наличие доступного аккаунта. Повторный запуск после ограничения одного аккаунта сохраняет неотправленных получателей в очереди и позволяет продолжить с доступного аккаунта.

Проверки: Ruff, форматирование, `compileall`, `pip check` и **239 автоматических тестов прошли** на Python 3.14.8. Сценарии отправки проверены с тестовой базой и заглушками Telegram; реальные сообщения не отправлялись.
