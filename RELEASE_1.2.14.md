# Inviter Studio 1.2.14

Исправлены две причины сбоя при запуске. Интерфейс больше не обновляет состояние кнопок до создания переключателя дополнительных настроек. В оконной сборке для Python заданы безопасные потоки вывода: сторонние библиотеки могут сообщать предупреждения без попытки писать в отсутствующую консоль.

Сохранены все исправления версии 1.2.12 и 1.2.13 для рассылки, повторных сообщений, импорта получателей, приглашений и прогрева.

Проверки: полный `tools/check_quality.ps1` — 248 автоматических тестов, Ruff, форматирование, `compileall` и `pip check`. Автоматические тесты используют заглушки Telegram и не отправляют реальные сообщения.
