# Inviter Studio 1.2.13

Исправлен сбой запуска `TaskTab object has no attribute advanced_switch`. При построении окна состояние кнопок больше не обновляется до создания всех элементов, которыми управляет эта функция.

Сохранены изменения версии 1.2.12: отложенные вторые сообщения отменяются после завершения/остановки задачи, отправленные первым сообщением пользователи не возвращаются в рассылку после повторного импорта, приглашения продолжаются через доступные аккаунты, а редактирование очереди блокируется на время задачи и импорта.

Проверки: полный `tools/check_quality.ps1`, включая Ruff, форматирование, `compileall`, `pip check` и 248 автоматических тестов. Отдельно будет проверен запуск собранного приложения в изолированном профиле без отправки сообщений Telegram.
