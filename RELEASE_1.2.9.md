# Inviter Studio 1.2.9

Продолжение аудита пользовательских сценариев после выпуска 1.2.8.

- Уведомления Windows сообщают о паузе Telegram, необходимости повторного входа и отклонении действия аккаунта. Уведомления краткие, без текста переписки, номеров и имён получателей; повторные одинаковые уведомления ограничены по частоте.
- В справке разъяснено, что закрытие рабочего соединения по окончании задачи не удаляет аккаунт и сохранённую сессию.
- Журнал можно экспортировать в TXT или XLSX с русскими названиями колонок. Текстовые поля записываются как обычный текст, поэтому содержимое журнала не интерпретируется Excel как формула.
- Добавлен `tools/check_quality.ps1` для повторяемого локального запуска линтера, проверки форматирования, синтаксиса, полного набора тестов и согласованности установленных зависимостей.

Проверки: Ruff, проверка форматирования, `compileall`, `pip check` и **238 автоматических тестов прошли** на Python 3.14.8. Установщик прошёл проверку выбора папки, ярлыков, обновления, запуска автономной сборки и удаления тестовой копии с сохранением профиля пользователя. Telegram-клиент в тестах заменён заглушками; реальные сообщения не отправлялись.

Для передачи подготовлена папка `ДЛЯ_УСТАНОВКИ`; достаточно отправить `InviterStudioSetup.exe`. Его SHA-256: `a8828ccdab6da1cc0ce550607b61bcc277a9ad8df4b73a72af89f3c67dadb48e`.

Остаются задачи, требующие внешней настройки: подпись установщика сертификатом издателя и периодический CI/аудит зависимостей. Без доверенного сертификата подпись не подтвердит издателя; локальная копия проекта не подключена к Git remote для автоматического CI.
