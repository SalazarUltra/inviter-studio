# Inviter Studio

Настольная программа для Windows: управление Telegram-аккаунтами, приглашения участников в группы и каналы, личные сообщения несколькими аккаунтами, сбор аудитории из открытых чатов и «прогрев» аккаунтов. Работает локально: данные и сессии хранятся только на вашем компьютере.

**Важно:** Telegram ограничивает массовые действия. Лимиты и прогрев снижают риск блокировок, но не гарантируют их отсутствие. Используйте свои аккаунты и соблюдайте правила Telegram.

## Установка

1. Откройте страницу [Релизы](https://github.com/SalazarUltra/inviter-studio/releases/latest).
2. Скачайте **`InviterStudioPortable.zip`**, распакуйте архив целиком в обычную папку и запустите `start.bat`.
3. `start.bat` сам снимает пометку «скачано из интернета» и запускает программу — вручную ничего разблокировать не нужно.
4. В portable-архиве уже есть Python-runtime и все библиотеки — ничего доустанавливать не нужно. Профиль сохраняется в папке `profile` рядом с `start.bat`.

Обновление portable-версии: закройте программу и запустите `update.bat` — он скачает ZIP только из официального GitHub-релиза, проверит SHA-256, заменит файлы приложения и сохранит `profile`. При необходимости ZIP можно скачать вручную и распаковать в новую папку.

**Проверка файлов.** Выпуск не подписан сертификатом издателя. Сравните SHA-256 ZIP со строкой в `SHA256.txt` (например, `Get-FileHash .\InviterStudioPortable.zip`). Скачивайте программу только из официального репозитория. Portable-формат не обходит Smart App Control: Windows всё равно может заблокировать неподписанный `InviterStudio.exe`.

**Если программа не запускается.** `start.bat` обычно снимает блокировку автоматически. Если на конкретном компьютере это не сработало (строгая политика Windows или антивирус): щёлкните правой кнопкой по `InviterStudio.exe`, выберите «Свойства», внизу вкладки «Общие» отметьте «Разблокировать» и нажмите ОК, затем снова `start.bat`. Если блокирует антивирус — добавьте папку программы в исключения. `start.bat` сам покажет эти шаги, если процесс не поднялся.

## Первые шаги

1. **Аккаунты** → добавьте свой номер Telegram, API ID и API Hash (кнопки в форме подскажут, где их взять), введите код из Telegram и пароль 2FA, если он есть.
2. **Аудитория** → вставьте список получателей: по одному @username или ссылке `t.me/...` на строку.
3. **Задача** → выберите группу (для приглашений нужны права администратора) или напишите текст сообщения, выберите аккаунты и интервал.
4. **Запустить задачу**. Программа должна оставаться открытой; о завершении придёт уведомление Windows.

Подробная инструкция — кнопка **«?»** или **F1** в любом разделе программы. Там же объяснение всех статусов получателей, парсинг, расписание и прогрев.

## Возможности

- **Приглашения** в группы и каналы с ротацией аккаунтов, дневными лимитами, расписанием и авто-перерывами.
- **Личные сообщения** несколькими аккаунтами с защитой от повторов (между аккаунтами и перезапусками) и вторым сообщением после ответа получателя.
- **Парсинг** участников групп и авторов сообщений с фильтрами (боты, Premium, активность) и экспортом в Excel/CSV/JSON/TXT.
- **Прогрев аккаунтов**: чтение, реакции и сообщения в выбранных вами чатах, при желании — генерация текстов через AI (OpenAI, Claude, Gemini, Grok).
- **Отчёты**: итоги кампании, журнал событий, экспорт аудитории в Excel со статусом, причиной и аккаунтом по каждому получателю.
- **Резервные копии** базы в один клик и ежедневные автоматические.

## Обновления

Portable-версия обновляется через `update.bat`: закройте программу, запустите скрипт — он скачает последний ZIP из официального релиза, проверит SHA-256, заменит файлы приложения и сохранит папку `profile`. Внутри программы кнопки обновления нет — скрипт делает всё сам и никогда не меняет файлы без проверки контрольной суммы.

Обновиться можно и вручную: скачайте новый `InviterStudioPortable.zip` из [последнего релиза](https://github.com/SalazarUltra/inviter-studio/releases/latest), распакуйте в новую папку и перенесите `profile` (при закрытой программе).

## Приватность и безопасность

- Данные, аккаунты и Telegram-сессии хранятся локально и никуда не отправляются: у portable-версии — в папке `profile` рядом с `start.bat`, у установленной — в `%LOCALAPPDATA%\InviterStudio`.
- API-ключи и пароли прокси дополнительно шифруются средствами Windows (DPAPI) для вашего пользователя.
- AI-функции подключаются только если вы сами добавите ключ провайдера; без него всё работает на локальных шаблонах.
- Ведите учёт того, кому передаёте файлы сессий: `sessions\*.session` дают доступ к аккаунту. При передаче программы другому человеку передавайте portable-архив без папки `profile`.

## Поддержать проект

Программа бесплатная. Если хотите поддержать разработку — кнопка «Поддержать проект» в программе (USDT/ETH, BNB — адреса и сети указаны в окне). Добровольно и без обязательств.

## Для разработчиков

Python 3.11+ (рекомендуется 3.14), Telethon, CustomTkinter, aiosqlite.

```powershell
py -3.14 -m venv .venv
.venv\Scripts\python.exe -m pip install -r requirements-lock.txt
.\start.bat                                  # запуск из исходников
.venv\Scripts\python.exe -m unittest discover -s tests -t .   # тесты (без сети и Telegram)
.\build.bat                                  # проверки качества + сборка установщика
```

GitHub Actions запускает Ruff, проверку форматирования, `compileall`, unit-тесты и `pip check` при push в `main` и для pull request. Локальный коммит сам по себе CI не запускает. Перед выпуском portable-архива запустите `build.bat`: он повторит quality gate и соберёт Windows-дистрибутив. Публикация релиза на GitHub выполняется отдельно.
