# Inviter Studio

Настольная программа для Windows: Telegram-аккаунты, приглашения, личные сообщения, парсинг аудитории и прогрев. Всё локально на вашем ПК.

**Важно:** Telegram ограничивает массовые действия. Пресеты темпа и лимиты снижают риск блокировок, но не убирают его. Используйте свои аккаунты и соблюдайте правила Telegram. Программа **не обходит** SpamBot, CAPTCHA и другие защиты Telegram.

## Установка (portable)

1. Откройте [последний релиз](https://github.com/SalazarUltra/inviter-studio/releases/latest).
2. Скачайте **`InviterStudioPortable.zip`** (при желании сверьте SHA-256 с `SHA256.txt`).
3. Распакуйте целиком и запустите `start.bat`.

После первого запуска появится папка **`profile`** — только ваши данные. Её нельзя публиковать или пересылать. В ZIP её нет.

**Обновление:** закройте программу → `update.bat` (не трогает `profile`).

**Не запускается?** Свойства `InviterStudio.exe` → «Разблокировать». Сборка не подписана — Smart App Control может блокировать.

## Первые шаги

1. **Аккаунты** — API ID/Hash, код, 2FA; укажите возраст (влияет на дневной лимит).
2. **Аудитория** — `@username`, `t.me/...`, или `id:123456` (для приглашений).
3. **Задача** — пресет темпа (Безопасный / Обычный / Быстрый), чат или текст, аккаунты.
4. **Запустить**. Программу оставьте открытой.

Справка: **«?»** или **F1**.

## Чеклисты

### Парсинг
1. Один или **несколько аккаунтов** (имя/@ник в списке) → источники → получить участников/авторов.
2. «Мои группы» в multi-режиме объединяет чаты отмеченных аккаунтов и показывает, **чей** это чат.
3. При обрыве — **«Продолжить»**; при FloodWait источники уходят на другие аккаунты.
4. Фильтры: без скама/фейков/админов; **«Новые с прошлого запуска»** — только diff.
5. «В аудиторию…» / экспорт XLSX·CSV·JSON·TXT; по желанию **«В бот (TXT)»** своему боту.

### Прогрев
1. Аккаунт → уровень → чаты → тема и тон AI → **Запустить**.
2. Можно **переключить аккаунт и запустить ещё один** параллельно; справа — активные прогревы и «Остановить все».
3. Тон (нейтральный / дружелюбный / экспертный) меняет стиль писем; блок «Запрос к ИИ» показывает актуальный prompt.

### Приглашения
1. Пресет темпа, порядок очереди, опционально **суточный лимит кампании**.
2. Дни недели + часы работы; умный интервал по локальному времени или **Москве**.
3. Опция **только прогретые аккаунты**.
4. Ошибка/пауза одного аккаунта не валит всю задачу.
5. Закрытым — **«Написать закрытым со ссылкой»**.

### Личные сообщения
1. Пресет **60–120 с** (минимум 45); агрессивные настройки — предупреждение до старта.
2. `{имя}`, `{a|b|c}`, предпросмотр, «Тест в Избранное», оценка срока.
3. Второе после ответа: задержка 30–180 с, TTL ожидания; **ожидания переживают перезапуск** (доставка — пока программа открыта).
4. Неизвестный результат отправки сверяется с историей чата; «Ушло» / «Не ушло» вручную.
5. Первые и вторые сообщения делят один дневной лимит аккаунта.

## Возможности (кратко)

| Блок | Что есть |
|---|---|
| Парсинг | Multi-account, имя/@, владелец в «Мои группы», resume, diff, бот TXT, XLSX |
| Прогрев | Несколько аккаунтов параллельно, тон AI, превью prompt, оценка $ |
| Инвайт | Ротация, ledger, пресеты, расписание по дням, TZ, cap |
| ЛС | Шаблоны, follow-up с persist, verify timeout, мост private→DM |
| Защита | Пресеты, warmup-gate, суточный потолок, без обхода Telegram |
| Данные | Portable `profile`, DPAPI, автобэкапы |
| Кампании | **Очередь** кампаний, **A/B-тексты**, импорт/экспорт JSON |
| Аналитика | **Дашборд конверсии**, сводки / свой бот (DPAPI), токены и оценка USD в AI-студии |
| Интерфейс | **RU/EN**, **светлая/тёмная тема**, **мастер первого запуска** |

## Приватность

Данные только в `profile`. API-ключи через Windows DPAPI. AI — только с вашим ключом. Не публикуйте `profile` и `*.session`.

## Для разработчиков

```powershell
py -3.14 -m venv .venv
.venv\Scripts\python.exe -m pip install -r requirements-lock.txt
.\start.bat
.venv\Scripts\python.exe -m unittest discover -s tests -t .
.\build.bat
```

`data/`, `sessions/`, `profile/`, `*.db` в git не попадают.
