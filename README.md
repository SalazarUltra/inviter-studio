# Inviter Studio

Настольная программа для Windows: Telegram-аккаунты, приглашения в группы и каналы, личные сообщения, сбор аудитории и прогрев. Всё работает локально на вашем компьютере.

**Важно:** Telegram ограничивает массовые действия. Лимиты и паузы снижают риск блокировок, но не убирают его. Используйте свои аккаунты и соблюдайте правила Telegram.

## Установка (portable)

1. Откройте [последний релиз](https://github.com/SalazarUltra/inviter-studio/releases/latest).
2. Скачайте **`InviterStudioPortable.zip`** (при желании сверьте SHA-256 с `SHA256.txt`).
3. Распакуйте архив целиком в обычную папку и запустите `start.bat`.

Python и всё нужное уже внутри. `start.bat` сам снимает пометку «скачано из интернета».

После первого запуска рядом с программой появится папка **`profile`**: база, настройки и сессии Telegram. Это только ваши данные — её нельзя публиковать, пересылать или класть в GitHub. В ZIP-релизе профиля нет.

**Обновление:** закройте программу и запустите `update.bat`. Он скачает ZIP только из официального релиза, проверит SHA-256 и не тронет `profile`. Вручную: распакуйте новый ZIP в новую папку и перенесите туда `profile` (при закрытой программе).

**Не запускается?** Правый клик по `InviterStudio.exe` → «Свойства» → «Разблокировать». Если мешает антивирус — добавьте папку программы в исключения. Сборка не подписана сертификатом издателя, поэтому Windows Smart App Control может её блокировать.

## Первые шаги

1. **Аккаунты** — номер Telegram, API ID и API Hash (с my.telegram.org), код и пароль 2FA. Возраст аккаунта в днях влияет на безопасный дневной лимит.
2. **Аудитория** — один `@username` или ссылка `t.me/...` на строку; можно импортировать из парсинга.
3. **Задача** — чат для приглашений (нужны права администратора) или текст личного сообщения, аккаунты и интервал.
4. **Запустить задачу**. Программа должна оставаться открытой.

Подробная справка внутри программы: кнопка **«?»** или **F1**.

## Чеклисты

### Парсинг
1. Выберите аккаунт и источники → **«Проверить доступ»** → получите участников или авторов сообщений.
2. При обрыве нажмите **«Продолжить»** — незавершённые источники доберутся без дублей.
3. Фильтры по умолчанию скрывают скам, фейки и ограниченных; админы в аудиторию не попадают (есть опция «включая»).
4. Перед «В аудиторию…» можно **исключить уже состоящих** в целевом чате и выбрать порядок. Уже приглашённые в этот чат (общий журнал) пропускаются.
5. Результат сохраняется в **XLSX / CSV / JSON / TXT**.

### Приглашения
1. Укажите чат, аккаунты, интервал и порядок очереди — аккаунты ротируются.
2. Если один аккаунт потерял права или получил паузу Telegram, остальные продолжают.
3. **«Повторить ошибки»** — отметьте нужные статусы; «Закрытый» и «Не найден» по умолчанию не возвращаются.
4. Закрытым получателям: **«Написать закрытым со ссылкой»** создаёт кампанию личных сообщений со ссылкой на чат. Отправка только после «Запустить».

### Личные сообщения
1. Режим «Личные сообщения»; интервал по умолчанию 60–120 с (минимум 45 с — защита от PeerFlood).
2. В тексте: `{имя}` и варианты `{привет|здравствуйте}`. Есть предпросмотр и «Тест в Избранное».
3. В шаге проверки — оценка срока (сколько уйдёт сегодня / за сколько дней при текущих лимитах).
4. Первые и вторые сообщения делят один дневной лимит аккаунта. Второе — только после ответа (задержка 30–180 с, «Ждать ответ» 1–168 ч).
5. «Остановить» при ожидающих вторых спросит подтверждение. В «Аудитории» у статуса «Проверить»: кнопки «Ушло» / «Не ушло».
6. «Написать закрытым со ссылкой» создаёт осторожную ЛС-кампанию (интервал ≥ 60 с).

## Возможности

- Приглашения с ротацией аккаунтов, лимитами, расписанием, перерывами и учётом уже приглашённых
- Личные сообщения с защитой от повторов, follow-up после ответа и мостом «закрытые → ЛС»
- Парсинг участников и авторов, продолжение прогона, экспорт XLSX/CSV/JSON/TXT
- Прогрев аккаунтов; тексты через AI (OpenAI, Claude, Gemini, Grok) — по желанию
- Резервные копии базы и ежедневные автокопии

## Приватность

- Данные и сессии хранятся только локально, в `profile` рядом с `start.bat`.
- API-ключи и пароли прокси шифруются Windows DPAPI для вашего пользователя.
- AI работает, только если вы сами добавили ключ провайдера.
- Файлы `*.session` и папка `profile` дают доступ к аккаунтам — не публикуйте их.
- Копия базы (`.db`) не содержит сессий целиком; для полного бэкапа копируйте всю папку `profile` при закрытой программе.

## Для разработчиков

Python 3.11+ (рекомендуется 3.14), Telethon, CustomTkinter, aiosqlite.

```powershell
py -3.14 -m venv .venv
.venv\Scripts\python.exe -m pip install -r requirements-lock.txt
.\start.bat
.venv\Scripts\python.exe -m unittest discover -s tests -t .
.\build.bat
```

Запуск из исходников хранит данные в `data/` и `sessions/`. Эти папки, `profile/` и `*.db` в git не попадают (см. `.gitignore`); `build.bat` проверяет, что в portable-архиве нет пользовательских данных.
