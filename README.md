# Inviter Studio

Настольная программа для Windows: Telegram-аккаунты, приглашения в группы и каналы, личные сообщения, сбор аудитории и прогрев аккаунтов. Всё работает локально на вашем компьютере.

**Важно:** Telegram ограничивает массовые действия. Лимиты и прогрев снижают риск блокировок, но не убирают его полностью. Используйте свои аккаунты и соблюдайте правила Telegram.

## Установка (portable)

1. Откройте [последний релиз](https://github.com/SalazarUltra/inviter-studio/releases/latest).
2. Скачайте **`InviterStudioPortable.zip`** (при желании сверьте SHA-256 с `SHA256.txt`).
3. Распакуйте архив целиком в обычную папку и запустите `start.bat`.
4. `start.bat` сам снимает пометку «скачано из интернета» и запускает программу.

В архиве уже есть runtime — ничего дополнительно ставить не нужно.

После первого запуска рядом с программой появится папка **`profile`**. В ней хранятся только ваши данные (база, аккаунты, сессии Telegram). Эту папку **нельзя** удалять, публиковать или отправлять другим людям.

### Обновление

Закройте программу и запустите `update.bat`. Скрипт скачает ZIP только из официального GitHub-релиза, проверит SHA-256, обновит файлы приложения и **не тронет** `profile`.

Можно обновиться вручную: скачайте новый ZIP, распакуйте в новую папку и перенесите туда свою папку `profile` (при закрытой программе).

### Если не запускается

Щёлкните правой кнопкой по `InviterStudio.exe` → **Свойства** → внизу «Общие» отметьте **Разблокировать** → ОК, затем снова `start.bat`. При блокировке антивирусом добавьте папку программы в исключения. Portable-сборка не подписана сертификатом издателя — Windows Smart App Control может требовать доверенный сертификат.

## Первые шаги

1. **Аккаунты** — добавьте номер Telegram, API ID и API Hash, введите код и пароль 2FA при необходимости. Укажите возраст аккаунта в днях — от него зависит безопасный дневной лимит.
2. **Аудитория** — список получателей: один `@username` или ссылка `t.me/...` на строку. Можно импортировать из парсинга.
3. **Задача** — группа для приглашений (нужны права администратора) или текст личного сообщения, аккаунты и интервал.
4. Нажмите **Запустить задачу**. Программа должна оставаться открытой; о завершении придёт уведомление Windows.

Подробная справка: кнопка **«?»** или **F1**.

## Короткий чеклист новых возможностей

### Парсинг → аудитория
1. Получите участников; при обрыве нажмите **«Продолжить»** — доберёт незавершённые источники.
2. В фильтрах по умолчанию скрыты скам/фейк/ограниченные; админы в аудиторию не попадают (есть опция «включая»).
3. Перед «В аудиторию…» при необходимости включите **исключить уже состоящих** в целевом чате.
4. Выберите порядок (как спарсили / по активности / перемешать) и кампанию — уже приглашённые в этот чат пропускаются.
5. Сохраните результат в **XLSX / CSV / JSON / TXT**.

### Приглашения
1. В «Задаче» задайте чат, аккаунты, интервал и **порядок** очереди.
2. Статус показывает успехи, пропуски, ошибки и ближайший свободный аккаунт.
3. Если один аккаунт потерял права или ушёл в паузу Telegram — остальные продолжают.
4. **«Повторить ошибки»** — отметьте только нужные статусы (по умолчанию ошибка и «проверить», не «закрытый»).
5. Для закрытых профилей: в «Аудитории» **«Написать закрытым со ссылкой»** — создаётся кампания личных сообщений со ссылкой на чат (отправка только после «Запустить»).

### Личные данные
- Portable пишет всё в папку `profile` рядом с `start.bat`. Её нельзя публиковать и класть в GitHub.
- Резервная копия `.db` — только для себя; сессии Telegram в неё не входят полностью (для полного бэкапа копируйте всю `profile` при закрытой программе).

## Возможности

- Приглашения с ротацией аккаунтов, лимитами, расписанием, перерывами и учётом уже приглашённых
- Личные сообщения с защитой от повторов и follow-up после ответа; мост «закрытые → ЛС»
- Парсинг участников и авторов, продолжение прогона, экспорт XLSX/CSV/JSON/TXT
- Прогрев аккаунтов; при желании — тексты через AI (OpenAI, Claude, Gemini, Grok)
- Резервные копии базы и ежедневные автокопии

## Приватность

- Данные и сессии хранятся только локально: у portable — в `profile` рядом с `start.bat`.
- API-ключи и пароли прокси шифруются Windows DPAPI для вашего пользователя.
- AI включается только если вы сами добавите ключ провайдера.
- Файлы `*.session` и папка `profile` дают доступ к аккаунтам — не публикуйте их в GitHub и не пересылайте вместе с программой.
- В репозитории и в ZIP-релизе **нет** пользовательских профилей: каждый пользователь начинает с пустыми данными.

## Поддержать проект

## Для разработчиков

Python 3.11+ (рекомендуется 3.14), Telethon, CustomTkinter, aiosqlite.

```powershell
py -3.14 -m venv .venv
.venv\Scripts\python.exe -m pip install -r requirements-lock.txt
.\start.bat
.venv\Scripts\python.exe -m unittest discover -s tests -t .
.\build.bat
```

Локальные `data/`, `sessions/`, `profile/` и `*.db` в git не попадают (см. `.gitignore`). Перед релизом `build.bat` проверяет, что в portable-архиве нет пользовательских данных.
