# TG Inviter Desktop

Настольное приложение для управления Telegram-аккаунтами, кампаниями приглашений и личных сообщений, а также действиями в выбранных чатах. Стек: Python, Telethon, CustomTkinter, asyncio и SQLite.

Повторный технический и визуальный аудит, исправления и предложения для выпуска 1.2.6: [AUDIT_2026-10-22.md](AUDIT_2026-10-22.md).

Изменения выпуска 1.2.15: [RELEASE_1.2.15.md](RELEASE_1.2.15.md). Ранее: [RELEASE_1.2.14.md](RELEASE_1.2.14.md).

Выпуски 1.2.13–1.2.14 исправляют сбои при запуске: интерфейс ждёт создания переключателя дополнительных настроек, а оконная EXE-сборка безопасно обрабатывает предупреждения библиотек без консольных потоков. Среда: Python 3.14.8 (Tk 9), Pillow 13.0.0 и aiohttp 3.14.4. Для исходников нужен Python 3.11 или новее; рекомендуется проверенная версия 3.14. Используйте отдельное виртуальное окружение. Реальные обращения к Telegram и платным AI API не входят в автоматические тесты.

## Установка готовой программы

Для передачи другому человеку используйте папку **ДЛЯ_УСТАНОВКИ** в корне проекта. В ней находятся `InviterStudioSetup.exe`, короткая инструкция и контрольная сумма SHA-256. Для самой установки достаточно **одного InviterStudioSetup.exe**; можно отправить всю эту папку для удобства.

Установщик предназначен для Windows 10/11 (64 бита), включает Python и необходимые библиотеки и не загружает их из интернета. Пользователь выбирает папку и ярлыки, затем добавляет свой Telegram-аккаунт, API ID и API Hash и подтверждает вход. Для работы нужен интернет; AI-провайдер подключается только для AI-функций. Донат добровольный. Архив исходников, `venv`, ваши `data`, `sessions` и ключи передавать не нужно. `InviterStudio.exe` из установленной папки требует соседнюю `_internal`; его нельзя путать с самостоятельным установщиком `InviterStudioSetup.exe`.

Этот выпуск не подписан сертификатом издателя. SHA-256 помогает сравнить файл с доверенной копией автора, но не заменяет цифровую подпись. Установщик можно копировать, а Python-сборка допускает извлечение байткода. Подробности технической проверки и пределы защиты — в [DISTRIBUTION_SECURITY.md](DISTRIBUTION_SECURITY.md).

## Запуск исходников (для разработчика)

```powershell
py -3.14 -m venv .venv
.venv\Scripts\python.exe -m pip install -r requirements-lock.txt
.\start.bat
```

`requirements.txt` содержит закреплённые прямые зависимости, `requirements-lock.txt` — все версии проверенного окружения. Не копируйте готовую папку окружения между компьютерами: создавайте её заново. `start.bat` и `build.bat` сначала используют `.venv`, затем прежнее `venv`. Старое окружение Python 3.10 не подходит для обновлённой Pillow; создайте `.venv` указанными командами. Готовый установщик включает нужный Python — пользователю ничего дополнительно устанавливать не нужно.

Можно запустить `.venv\Scripts\python.exe main.py`. При запуске исходников база и сессии находятся рядом с проектом, независимо от текущего каталога. Установленная версия хранит их в `%LOCALAPPDATA%\InviterStudio`; переменная `INVITER_HOME` позволяет явно выбрать профиль. Второй экземпляр приложения с теми же данными блокируется.

## Интерфейс Studio

Все экраны оформлены в единой графитовой теме с лаймовым акцентом. Боковое меню сворачивается на небольшом окне; Ctrl+1…8 переключает разделы. В задаче доступны быстрые переходы к группам настроек. Подробности и результаты проверки — в [DESIGN.md](DESIGN.md).

Для первого запуска откройте «Пошаговая инструкция» в «Обзоре». Кнопка «?» или F1 открывает справку по текущему экрану. В справке доступны поиск и темы по всем разделам, включая парсинг, статусы и сохранение данных. Справка работает без интернета; кнопки внизу ведут к аккаунтам, аудитории и задаче. Наведите курсор на важные кнопки и поля, чтобы прочитать короткое пояснение.

Если Telegram отклонил отправку, запись аккаунта и сессия остаются в программе; закрытие рабочего соединения в журнале не означает удаления аккаунта. Проверка авторизации не подтверждает право написать каждому получателю. Сведения о сетевом подключении, ключах AmneziaVPN и пределах проверки описаны в [TELEGRAM_AND_VPN_AUDIT.md](TELEGRAM_AND_VPN_AUDIT.md).

«Настроить задачу» в верхней панели открывает настройки текущей кампании. «Открыть аудиторию» внутри задачи ведёт к списку её получателей. «Что значат статусы?» в аудитории объясняет результаты и необходимые действия. В «Журнале» можно выбрать кампанию; основные события отображаются по-русски с аккаунтом и получателем, если они записаны в событии.

Настройка задачи состоит из четырёх шагов: **Получатели → Сообщение / чат → Аккаунты и темп → Проверка**. «Далее», «Назад» и кнопки шагов ничего не отправляют. Реальные действия начинаются только по кнопке «Запустить задачу» на последнем шаге. Изменённый список нужно сохранить; попытка запуска с несохранённым списком вернёт к получателям. В итоговой проверке видны текст, аккаунты, интервал, расписание и перерывы. Переключатель «Расписание и перерывы» на третьем шаге показывает дополнительные поля, сохраняя их действие при скрытии. «Выбрать все» и «Снять выбор» управляют доступными аккаунтами.

В парсинге доступны два экрана: **Настройка парсинга** и **Результаты и сохранение**. После завершения второй открывается автоматически. Фильтры и отчёт об источниках можно раскрыть отдельно. Кнопка «Сохранить файл на ПК» находится вверху результатов; выгружается весь отфильтрованный список, а не только текущая страница.

Переключатель **«Уведомления Windows»** внизу окна сохраняет выбор для всей программы. Уведомления сообщают о завершении задачи, результатах парсинга и ошибках операций парсинга, без номеров аккаунтов и текстов переписки. Используется встроенный API Windows, без дополнительных библиотек. Режим «Не беспокоить» и настройки Windows могут скрыть уведомления; результаты также остаются в приложении. После закрытия программы задачи не выполняются.

В режиме личных сообщений кнопка «Шаблоны…» открывает общую библиотеку текстов. Шаблон можно создать, изменить, удалить или вставить в текущую задачу без отправки. При замене непустого текста требуется подтверждение. Шаблоны сохраняются в базе и попадают в её резервную копию. Счётчик рядом с текстом показывает длину в единицах UTF-16: эмодзи могут занимать две. Дневной лимит аккаунта применяется к первым личным сообщениям. Вторые сообщения после ответа расходуют собственный дневной счётчик с тем же лимитом и не блокируются достижением квоты первых сообщений; ожидание Telegram и перерыв аккаунта продолжают действовать.

Кнопка «⋯» рядом с выбором кампании позволяет переименовать её или создать новую с копией **сохранённых** настроек. Аудитория, события, история запусков и состояние выполнения не копируются. Защита от повторных сообщений остаётся общей. Перед копированием сохраните параметры задачи.

В «Аккаунтах» доступны поиск телефона и фильтры состояния. В «Журнале» — поиск никнейма, телефона или события, фильтры успехов/пропусков/ошибок и «Обновить». Поиск охватывает последние 2000 загруженных событий; экспорт включает весь журнал независимо от фильтра. Текст журнала и последних событий обзора доступен только для чтения и копирования.

Сравнение продуктов, изменения по всем вкладкам и предложения для следующего этапа — [MARKET_REVIEW.md](MARKET_REVIEW.md).

## Основной сценарий

1. На вкладке «Аккаунты» добавьте телефон в международном формате, API ID и API Hash, полученные для своего Telegram-приложения. Введите код Telegram и, при необходимости, пароль 2FA.
2. При необходимости задайте прокси SOCKS5 или HTTP. Логин и пароль прокси можно задать при добавлении аккаунта и поменять через «Изменить». Перед сменой прокси остановите операции аккаунта. Переключатель «Использовать» разрешает участие аккаунта в задачах, но сам задачу не запускает. Ручная смена состояния не отменяет назначенную Telegram паузу.
3. На вкладке «Аудитория» нажмите «Вставить / изменить список» или импортируйте UTF-8 TXT: один username, `@username` или публичная ссылка `https://t.me/username` на строку. Пустые строки и строки с `#` пропускаются. Повторы удаляются; некорректная строка выводится с номером, весь ошибочный список отклоняется.
4. На вкладке «Задача» укажите публичный username группы/канала, включённые аккаунты, интервал и расписание. Приватные invite-ссылки здесь не поддерживаются. Приватные чаты доступны в прогреве после синхронизации списка диалогов.
5. «Пауза» приостанавливает последующие действия. «Стоп» прерывает ожидание; уже отправленный Telegram-запрос завершается и учитывается. При закрытии приложение завершает фоновые операции, затем закрывает клиентов.

Настройки задачи прокручиваются, кнопки управления остаются видимыми. Окно поддерживает размер от 900×600 и масштабирование Windows.

Telegram-аккаунту нужны права администратора с правом приглашения в выбранный чат. Учитываются уже существующее членство, приватность пользователя и список `missing_invitees` в ответе Telegram. Приложение не считает ответ запроса доказательством добавления, если Telegram сообщает о невозможности приглашения.

Дневной лимит `0` запрещает приглашения. Для неизвестного возраста аккаунта применяется консервативное ограничение до 10 приглашений в день; поле возраста не определяет реальную дату регистрации Telegram. Лимиты и прогрев не гарантируют отсутствие ограничений со стороны Telegram.

## Ограничения и восстановление

- `FloodWait`: аккаунт пропускается до указанного Telegram срока. Ожидание не сбрасывается при подключении.
- `restricted`: Telegram вернул `PeerFlood`; автоматические действия этого аккаунта прекращаются.
- Несуществующий или чужой тип никнейма отмечается «Не найден» и записывается в журнал как пропуск. Следующий получатель обрабатывается без ожидания; такой пропуск не переводит аккаунт в `restricted`.
- `unauthorized`: сессия отозвана или не авторизована. Требуется повторный вход.
- `PeerFlood` при запросе отправки означает, что Telegram отклонил действие с аккаунта. Невыполненный получатель остаётся в очереди, кампания останавливается, а выбранный ограниченный аккаунт блокирует новый запуск. В «Журнале» видна точная причина. После проверки ситуации в Telegram состояние можно изменить через «Изменить». Кнопка «Проверить» проверяет только вход и соединение; её положительный результат не доказывает снятие ограничения отправки.
- Очистка списка во время активной задачи запрещена. Удаление занятой сессии запрещено.
- После аварийного завершения цели `processing` восстанавливаются в `pending`. Если запрос дошёл до сервера перед обрывом, результат может оставаться неопределённым; следующая попытка сначала проверяет членство. Это не гарантия доставки ровно один раз при любых сетевых сбоях.

Итог задачи содержит результаты текущего запуска. Общие показатели списка сохраняются отдельно. Ошибки и пропуски не дублируются в статистике.

## Прогрев и AI

Сначала выберите аккаунт, обновите список диалогов и отметьте конкретные каналы/группы. Синхронизация сохраняет выбор. Без выбранных чатов прогрев не запускает действий; автоматического вступления в посторонние каналы нет. Вещательные каналы исключены из отправки сообщений.

Лёгкий режим выполняет действия чтения и реакций; средний и интенсивный могут отправлять сообщения в выбранные группы. При `FloodWait`, отзыве сессии или ограничении аккаунта прогрев прекращается. Дневная квота выбирается один раз и сохраняется между перезапусками.

На вкладке «AI» можно добавить OpenAI, Anthropic, Gemini или xAI. Поле модели позволяет ввести собственный API ID модели. Подсказки моделей не гарантируют доступность для вашего аккаунта — проверьте её в кабинете провайдера.

Без конфигурации используются локальные шаблоны. Если настроенный API возвращает ошибку, сообщение не заменяется шаблоном незаметно: ошибка отображается, отправка пропускается. Учёт токенов берётся из ответа API. Стоимость смотрите в кабинете провайдера; приложение не выдаёт произвольные тарифы за фактический счёт.

Память AI хранит контекст и ответы для выбранного аккаунта и чата. При отключённой памяти содержимое диалога не сохраняется в таблицах памяти. Время отправки и идентификатор чата сохраняются отдельно для лимитов; отключение или очистка памяти не отключает лимит сообщений. Минимальный журнал отправок хранится до 7 дней и очищается при следующей отправке. Контекст выбранного чата передаётся настроенному AI-провайдеру при генерации.

## Данные и ключи

- `data/inviter.db` — база, настройки, логи и память AI.
- `sessions/*.session` — сессии Telethon. Эти файлы позволяют использовать авторизацию аккаунта; не публикуйте их.
- В Windows API Hash, пароль прокси и AI-ключи защищаются DPAPI текущего пользователя. Старые открытые значения шифруются при следующем запуске приложения. Шифрование проверено на копии существующей базы.
- DPAPI привязан к пользователю Windows. Перенос зашифрованной базы в другой профиль/на другой компьютер требует повторного ввода реквизитов. Телефоны, логи, память и сами сессии Telethon этой защитой не шифруются.
- На других ОС DPAPI не применяется; хранение реквизитов использует защиту файловой системы, этот режим отдельно не проверен.
- `.gitignore` исключает данные, сессии, окружения, секреты и локальные материалы аудита. Уже опубликованные файлы этим не удаляются из истории.

Перед обновлениями сохраняйте резервную копию базы через SQLite Backup API и копию сессий при остановленном приложении. Обычное копирование работающего SQLite-файла без WAL может дать неполную копию.

В `.audit/baseline/` сохранены локальные резервные копии исходников и базы до аудита. База в этой копии может содержать незашифрованные реквизиты; храните её как приватный файл. Во время аудита рабочая база и существующие сессии не изменялись.

## Кампании, диагностика и отчёты

На экранах «Аудитория» и «Задача» выберите кампанию или создайте новую. У каждой кампании своя очередь, результаты, чат, интервалы, расписание, перерывы и выбранные аккаунты. Одинаковый username может присутствовать в разных кампаниях. Аккаунты, дневные лимиты, AI-подключения и настройки прогрева общие. Одновременно выполняется одна кампания — приглашения или личные сообщения; переключение кампании во время задачи или диагностики блокируется.

Существующая очередь автоматически переносится в «Основную кампанию» при первом запуске. Нажмите «Сохранить настройки» перед переключением, чтобы сохранить изменения формы. Повторный запуск продолжает ожидающую очередь; уже обработанные записи не выполняются повторно. После перезапуска приложение не начинает отправку автоматически. «Отчёт» показывает результаты по аккаунтам и последние 100 запусков с исходом и длительностью. Экспорт CSV и журнал относятся к выбранной кампании.

«Предпросмотр» проверяет настройки, очередь и лимиты без подключения к Telegram. «Проверить подключение» дополнительно проверяет авторизованную сессию, соединение через настроенный прокси и права приглашения; сообщения и приглашения не отправляются. Перед запуском такая проверка выполняется автоматически. Она не гарантирует отсутствие будущих ограничений Telegram или согласие пользователя на приглашение.

В аудитории доступны поиск по username, все статусы и страницы по 100 строк. Статистика, CSV и Excel (XLSX) включают всю очередь, а не только открытую страницу; в XLSX-отчёте — получатель, результат, причина, аккаунт и дата обработки.

«Вставить / изменить список» открывает редактор всех ожидающих получателей выбранной кампании, независимо от фильтра и страницы. Вставьте список через Ctrl+V, контекстное меню или кнопку «Вставить»; строки можно редактировать и удалять. «Сохранить список» заменяет только ожидающую очередь и сохраняет порядок строк. Обработанные записи, результаты и журнал защиты от повторных сообщений остаются. Для очистки ожидающих нажмите «Очистить поле», затем «Сохранить список» и подтвердите очистку. Очистка поля без сохранения не меняет очередь; «Отмена» позволяет закрыть редактор без применения изменений. Сохранённый список доступен после перезапуска.

Редактировать очередь можно после остановки задачи. Если очередь изменилась, пока редактор был открыт, сохранение отклоняется: откройте его заново для загрузки актуального списка. Некорректные строки и ошибки записи не удаляют текущую очередь. Сохранение списка записывается в журнал выбранной кампании. Импорт TXT по-прежнему добавляет получателей к очереди; «Очистить всё» удаляет все строки аудитории, включая результаты, с сохранением отдельного журнала защиты от повторов. На небольшом окне заголовок и крупная статистика сворачиваются, освобождая место таблице.

В AI-студии «Проверить AI / показать пример» выполняет один запрос к выбранной модели с введённым контекстом и показывает ответ и расход токенов. Применяется тариф провайдера; сообщения в Telegram не отправляются и память диалогов не изменяется. Доступность ключа, модели и квоты подтверждается только успешным реальным запросом.

## Резервные копии

«Копии данных» позволяет сохранить `.db` и выбрать копию для восстановления при следующем запуске. До восстановления сохраняется текущая база. При запуске выполняется не более одной автоматической копии в день; сохраняются последние 7 автоматических копий в `data/backups`. Ручные копии автоматически не удаляются. Копии содержат кампании, настройки, аккаунты, историю и память AI; API-ключи защищаются DPAPI на Windows, в том числе при копировании старой базы.

**Копия базы не включает Telegram-сессии.** Для переноса полного профиля при закрытой программе отдельно сохраните папки `data` и `sessions`. Для расшифровки DPAPI нужен исходный пользователь Windows; на другом компьютере может потребоваться повторный ввод ключей и авторизация. Восстановление заменяет базу целиком, поэтому изменения после выбора копии не попадут в восстановленное состояние.

## Windows-приложение и установщик

При первом запуске профиля один раз появляется необязательное окно «Поддержать проект». Его можно закрыть без доната и открыть снова кнопкой на обзоре или сердечком в боковом меню. Отметка показа общая для всех кампаний и сохраняется в базе профиля. В окне доступен полный адрес `0x3EDdE055dED28684fEA81155af8891332f9B7B23` и кнопка копирования. Сети и валюты подписаны отдельно: USDT (ERC-20) и ETH в Ethereum; USDT (BEP-20) и BNB в BNB Smart Chain. Ссылок на обозреватели в окне нет. Программа не подключает кошелёк и не выполняет перевод.

Для передачи другому человеку достаточно одного файла `dist/InviterStudioSetup.exe`. Это мастер установки Inno Setup с русским и английским интерфейсом: приветствие, выбор папки, флажки ярлыков на рабочем столе и в меню «Пуск», подтверждение установки и запуск после завершения. По умолчанию предлагается `%LOCALAPPDATA%\Programs\InviterStudio`; можно выбрать отдельную папку на другом диске. Установка выполняется для текущего пользователя Windows без обязательных прав администратора; выбранная папка должна быть доступна для записи. Поддерживается 64-разрядная Windows 10/11. Python и компилятор на компьютере получателя не нужны.

Для обновления закройте Inviter Studio и запустите новый установщик: папка и параметры ярлыков запоминаются. Запущенная новая версия обнаруживается установщиком и деинсталлятором; принудительное закрытие не используется. Удаление доступно через «Параметры Windows → Приложения → Установленные приложения → Inviter Studio». База, аккаунты, Telegram-сессии и результаты в `%LOCALAPPDATA%\InviterStudio` сохраняются после обновления и удаления программы. Дополнительные пользовательские файлы в папке программы не удаляются. Данные и Telegram-сессии автора в установщик не включаются; сборка также проверяет отсутствие пользовательских файлов в пакете.

Для запуска собранной версии **с текущими данными проекта** используйте `start-exe.bat`. Он выбирает последний успешно собранный выпуск. Новые сборки создаются в отдельных папках `dist/releases/<сборка>/InviterStudio`, чтобы не перезаписывать открытый EXE; `dist/release.json` указывает актуальную папку. Старый `dist/InviterStudio` остаётся запасным вариантом для прежних сборок. Если нужна версия без установки, передавайте всю папку актуального выпуска вместе с `_internal`, а не один `InviterStudio.exe`. Обычный запуск `.exe` или установка использует отдельный профиль в AppData. При смене способа запуска переносите данные только при закрытых экземплярах программы.

Сборка: установите `requirements-lock.txt` и `requirements-build.txt`, затем подготовьте компилятор командой `powershell -File tools/bootstrap_inno.ps1`. Она загружает официальный Inno Setup 6.7.3, проверяет закреплённый SHA-256 и подпись Pyrsys B.V. и распаковывает компилятор в portable-режиме внутри `.audit/tooling/inno`, без системной регистрации. Можно использовать установленный Inno Setup 6.7.3+ или задать путь через `INNO_SETUP_COMPILER`. Выполните `.venv\Scripts\python.exe -m tools.build_windows` (или `build.bat`); `--installer-only` пересобирает мастер из последнего выпуска. `build.bat` перед сборкой прогоняет контроль качества: Ruff, форматирование, `compileall`, полный набор тестов и `pip check` — дистрибутив не собирается из сломанного кода. Подпись кода включается переменными окружения: `INVITER_SIGNING_THUMBPRINT` (SHA-1 отпечаток сертификата текущего пользователя) и при необходимости `SIGNTOOL_PATH`/`INVITER_TIMESTAMP_URL`; без них сборка остаётся без подписи, как раньше. Сборка использует [PyInstaller](https://pyinstaller.org/en/stable/usage.html) и [Inno Setup](https://jrsoftware.org/isinfo.php); сценарий мастера — `tools/installer/inviter.iss`. Без настроенного сертификата установщик не подписан издателем.


## Подключение AI

Для подключения AI откройте «AI-студию»: выберите провайдера, нажмите «Получить ключ» и следуйте подсказке его кабинета. Вставьте API-ключ (кнопка или Ctrl+V), выберите модель, задайте название и сохраните. Сохранение не проверяет ключ и не вызывает API; «Проверить AI» выполняет один запрос по тарифу, только после ввода темы. Затем нажмите «Активировать» справа. AI используется в прогреве; обычная рассылка отправляет ваш готовый текст и не требует AI-ключа. Подписка на чат не гарантирует API-квоту: баланс и лимиты проверяйте в кабинете провайдера.

Подборка текстовых моделей сверена 15.10.2026: OpenAI — `gpt-6-luna`, `gpt-6.1-sol`, `gpt-6-astra`; Claude — `claude-haiku-5-5`, `claude-sonnet-5-5`; Gemini — `gemini-3.5-flash-lite`, `gemini-3.8-flash`; Grok — `grok-4.7`. Это стартовые варианты, а не полный каталог и не гарантия доступа вашему ключу. Кнопка «Модели» ведёт в официальный каталог; можно ввести другой ID вручную. Сохранённые подключения не меняются автоматически. «Изменить» позволяет заменить модель или ключ с сохранением счётчика и активации; для применения к уже работающему прогреву перезапустите его. При переключении провайдера в форме прежний ключ очищается. Подробные инструкции доступны по F1.

## Личные сообщения несколькими аккаунтами

Удаление кампании доступно кнопкой «Удалить» в панели кампаний на вкладках «Задача» и «Аудитория», а также в меню «⋯». Сначала остановите задачу. Подтверждение удаляет список, настройки, журнал и отчёты выбранной кампании, отменяет ожидающие вторые сообщения и открывает другую кампанию. Если удалена последняя, создаётся новая пустая. Аккаунты, AI, результаты парсинга и другие кампании сохраняются. Служебные записи о доставке сохраняют защиту от повторной рассылки; текст второго сообщения в них очищается. Для восстановления нужна заранее сделанная копия базы.

В форме добавления Telegram-аккаунта есть кнопки «Получить API ID и API Hash» (официальный my.telegram.org/apps) и «Пошагово: где взять данные». Инструкция объясняет создание приложения Desktop, поля формы, копирование реквизитов, различие кода для сайта и кода для входа в программу, а также пароль 2FA.

1. На экране «Задача» или «Аудитория» нажмите «+ Кампания», выберите режим «Личные сообщения» и задайте название. Режим кампании с результатами менять нельзя: для другого действия создайте новую кампанию.
2. Прямо в «Задаче» вставьте @никнеймы по одному на строку в поле «Кому отправлять · список получателей» через Ctrl+V или кнопку «Вставить». Нажмите «Сохранить список». Здесь же можно изменить или очистить поле; для удаления ожидающей очереди сохраните пустое поле и подтвердите. «Обновить» загружает сохранённый список заново. В «Аудитории» доступен тот же список и импорт TXT. Одна общая очередь используется всеми выбранными аккаунтами; повторы объединяются. Обработанные результаты и защита от повторов сохраняются. Программа предупредит о несохранённом списке перед запуском, выходом или сменой кампании.
3. В «Задаче» введите текст сообщения и выберите аккаунты. Текст отправляется как обычный текст, с сохранением переносов строк, без AI и подстановок. Максимальная длина — 4096 единиц UTF-16; некоторые эмодзи занимают две.
4. Задайте минимальный и максимальный интервал в секундах (10–86400). Для фиксированной паузы поставьте одинаковые значения: например, 60 и 60 — одно новое сообщение примерно раз в минуту на всю очередь. Аккаунты используются по очереди, а не отправляют одновременно. Обработка запросов, расписание, паузы и ограничения могут увеличить интервал.
5. Нажмите «Предпросмотр» для проверки текста и настроек без отправки. «Проверить подключение» проверяет сессии и прокси; целевой чат и права администратора в этом режиме не нужны. «Запустить задачу» начинает отправку. Программа должна оставаться открытой.

Защита от повторов действует между аккаунтами, кампаниями и перезапусками. Журнал сохраняет username и Telegram ID получателя: разные username одного человека не приводят к двум отправкам. Очистка списка и повторный импорт не удаляют журнал. Статусы: «Отправлено», «Без повтора», «Закрытый» и «Проверить». Отправлено означает, что Telegram подтвердил запрос, а не то, что человек прочитал сообщение.

При обрыве связи или отмене незавершённого запроса результат может остаться неизвестным. Приложение отмечает его «Проверить» и не отправляет повтор автоматически. Проверяйте такую переписку вручную. Восстановление старой базы возвращает журнал к состоянию этой копии: более поздние отправки в ней отсутствуют.

Дневные лимиты сообщений учитываются отдельно от приглашений, но задаются тем же лимитом аккаунта и общими консервативными ограничениями. При FloodWait, ограничении аккаунта или отзыве сессии останавливается вся кампания; отправка не продолжается с других аккаунтов. Пользователи с запретом сообщений также не обходятся сменой аккаунта. Пауза и стоп не отменяют уже принятый Telegram запрос.

Реальные личные сообщения при разработке не отправлялись. Проверены имитация Telegram, общая очередь для 10 аккаунтов, сохранение текста, интервалы, журнал, сбои и интерфейс. Низкий интервал не гарантирует отсутствия ограничений Telegram. Вызов отправки и идентификатор запроса соответствуют [Telegram messages.sendMessage](https://core.telegram.org/method/messages.sendMessage).


## Второе сообщение после ответа

В режиме «Личные сообщения» доступна опция «Второе сообщение — только после ответа». Заполните первое сообщение и второй текст, включите опцию и запустите задачу. Второе сообщение отправляется один раз тем же аккаунтом после нового входящего сообщения от получателя, появившегося после подтверждённого первого. Старые сообщения, реакции, прочтения, исходящие и служебные записи условие не выполняют; обычное входящее сообщение с медиа выполняет. Без ответа второй отправки нет. Для новых получателей сохраняется снимок второго текста; изменение формы не заменяет текст уже ожидающих сообщений.

Ответы обрабатываются при работающей задаче, включая ожидание после окончания первой очереди. Второе сообщение не ждёт случайный интервал первых сообщений, но учитывает паузу, расписание, ротационные перерывы и собственную дневную квоту с тем же лимитом аккаунта. Ограничение Telegram останавливает всю кампанию. Остановка задачи и выход из программы отменяют ещё не отправленные вторые сообщения (исход виден в журнале и в итоговом счётчике); первые отправки и защита от повторов сохраняются. История переписок постепенно проверяется на ответы, полученные во время отсутствия программы; автоматического запуска при открытии нет. Выключенный режим не исполняет сохранённые ожидания. Если ожидания остались после сбоя завершения, их отменит кнопка «Отменить ожидающие вторые сообщения» без удаления первых отправок и защиты от повторов.

Счётчики вторых сообщений видны в задаче, исход каждого — в примечании аудитории и журнале кампании. При известной блокировке или запрете второе сообщение не отправляется успешно, смена аккаунта и повтор отключены. Скрытую блокировку со стороны получателя сразу после его ответа Telegram не всегда позволяет определить: [userFull.blocked](https://core.telegram.org/constructor/userFull) описывает блокировку, установленную владельцем аккаунта. Подтверждение API означает принятие отправки, а не доставку/прочтение. При неизвестном исходе отправки или аварийном завершении во время запроса второе сообщение требует ручной проверки и не повторяется автоматически.

Для этой функции используются [NewMessage](https://docs.telethon.dev/en/stable/modules/events.html#telethon.events.newmessage.NewMessage) и [история сообщений](https://docs.telethon.dev/en/stable/modules/client.html#telethon.client.messages.MessageMethods.iter_messages). Входящие тексты и медиа не сохраняются: в журнал ожиданий попадают идентификаторы получателя, аккаунта, первого сообщения/ответа и настроенный второй текст.

## Вставка текста и выход из приложения

Ctrl+V, Ctrl+C, Ctrl+X и Ctrl+A работают в полях ввода и многострочном тексте независимо от русской или английской раскладки. Доступны Shift+Insert и меню правой кнопки мыши. У полей первого и второго сообщения есть отдельные кнопки «Вставить». Вставка заменяет выделенный фрагмент; переносы строк многострочного текста сохраняются. Поля с отключённым редактированием остаются защищены от изменения.

Текст личного сообщения сохраняется автоматически после редактирования, при переключении кампании и перед обычным выходом. Это работает и для незавершённого черновика без выбранных аккаунтов или до проверки длины сообщения. При следующем запуске восстанавливаются последняя выбранная кампания и её текст. Для остальных параметров формы используйте «Сохранить настройки». Не добавленные через авторизацию аккаунты и несохранённые формы подключения AI не считаются сохранёнными настройками.

Выход сохраняет добавленные аккаунты, сессии, аудиторию, результаты и журнал защиты от повторов. Активная задача останавливается и не запускается автоматически после открытия: запустите её вручную. Если сохранить данные перед выходом не удалось, окно остаётся открытым, чтобы можно было скопировать текст и повторить сохранение. При аварийном завершении Windows последние изменения между автосохранениями могут не успеть записаться.

Используйте тот же способ запуска и профиль данных: start-exe.bat работает с данными проекта, а обычный запуск установленной версии — с профилем в AppData. Обновление исходников не обновляет уже установленную копию: установите новый dist/InviterStudioSetup.exe при закрытом приложении.

## Парсинг групп и каналов

Вкладка «Парсинг» (Ctrl+8) получает доступных участников либо авторов доступных сообщений выбранным аккаунтом. Режим задаётся в поле «Что получить». Публичные адреса вставляются по одному на строку; приватные группы выбираются из «Моих групп» после ручного вступления. «Проверить доступ» проверяет первый источник для выбранного режима. Программа автоматически не вступает и не отправляет сообщения.

Результаты сохраняются по запускам и источникам. Есть фильтры по никнейму, ботам, удалённым профилям, роли, видимой активности, фото и Premium; поиск имени/ID, группировка и объединение повторов по Telegram ID. CSV/JSON выгружают весь выбранный сегмент с источниками, TXT — никнеймы. Отдельное подтверждённое действие добавляет никнеймы в аудиторию кампании без запуска отправки. Публичность источника не гарантирует полного списка, а для подписчиков канала часто нужны права администратора. Подробные шаги, форматы и таблица доступа — в [PARSING.md](PARSING.md) и справке F1 внутри вкладки.

«Авторы сообщений» просматривает выбранный период — 7/30/90 дней, свои даты или всю доступную историю — с лимитом до 10000 сообщений на источник и 20000 за запуск. У людей сохраняются число найденных сообщений и даты первого/последнего найденного сообщения; есть соответствующие фильтры, группировка и CSV/JSON. Тексты и вложения не сохраняются, анонимные сообщения не раскрывают человека. Автор сообщения мог уже покинуть группу, его роль не проверяется. Доступ к истории проверяется отдельно от доступа к списку участников; комментарии к каналу ищутся в отдельно выбранной группе обсуждения.

Чтобы получить файл на компьютере, выберите сохранённый запуск и нажмите видимую сверху кнопку «Сохранить файл на ПК». Рядом выбирается CSV/Excel, TXT или JSON. В окне Windows укажите папку и подтвердите сохранение. Затем «Открыть папку» покажет файл в Проводнике; последний путь запоминается. Сам парсинг сохраняет результат внутри программы, но не создаёт отдельный экспорт автоматически. Для экспорта существующего результата повторное подключение к Telegram не требуется.
