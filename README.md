# Inviter Studio

Настольная программа для Windows: управление Telegram-аккаунтами, приглашения участников в группы и каналы, личные сообщения несколькими аккаунтами, сбор аудитории из открытых чатов и «прогрев» аккаунтов. Работает локально: данные и сессии хранятся только на вашем компьютере.

**Важно:** Telegram ограничивает массовые действия. Лимиты и прогрев снижают риск блокировок, но не гарантируют их отсутствие. Используйте свои аккаунты и соблюдайте правила Telegram.

## Установка

1. Откройте страницу [Релизы](https://github.com/SalazarUltra/inviter-studio/releases/latest).
2. Скачайте **`InviterStudioSetup.exe`** (рядом лежит `SHA256.txt` для проверки).
3. Запустите установщик: нужны Windows 10/11 (64 бита) и интернет. Python и библиотеки уже внутри — ничего доустанавливать не нужно.
4. После установки ярлык «Inviter Studio» появится на рабочем столе и в меню «Пуск».

Обновление: запустите новый `InviterStudioSetup.exe` поверх старой версии — папка, данные, аккаунты и результаты сохраняются. Удаление — через «Параметры Windows → Приложения»; ваши данные при этом остаются на диске.

**Проверка файла.** Выпуск не подписан сертификатом издателя. Чтобы убедиться, что файл оригинальный, сравните его хеш со строкой в `SHA256.txt` (в PowerShell: `Get-FileHash .\InviterStudioSetup.exe`). Скачивайте программу только из официального репозитория.

## Первые шаги

1. **Аккаунты** → добавьте свой номер Telegram, API ID и API Hash (кнопки в форме подскажут, где их взять), введите код из Telegram и пароль 2FA, если он есть.
2. **Аудитория** → вставьте список получателей: по одному @username или ссылке `t.me/...` на строку.
3. **Задача** → выберите группу (для приглашений нужны права администратора) или напишите текст сообщения, выберите аккаунты и интервал.
4. **Запустить задачу**. Программа должна оставаться открытой; о завершении придёт уведомление Windows.

Подробная инструкция — кнопка **«?»** или **F1** в любом разделе программы. Там же объяснение всех статусов получателей, парсинг, расписание и прогрев.

## Возможности

- **Приглашения** в группы и каналы с ротацией аккаунтов, дневными лимитами, расписанием и авто-перерывами.
- **Личные сообщения** несколькими аккаунтами с защитой от повторов (между аккаунтами и перезапусками) и вторым сообщением после ответа получателя.
- **Парсинг** участников групп и авторов сообщений с фильтрами (боты, Premium, активность) и экспортом в Excel/CSV/JSON/TXT.
- **Прогрев аккаунтов**: чтение, реакции и сообщения в выбранных вами чатах, при желании — генерация текстов через AI (OpenAI, Claude, Gemini, Grok).
- **Отчёты**: итоги кампании, журнал событий, экспорт аудитории в Excel со статусом, причиной и аккаунтом по каждому получателю.
- **Резервные копии** базы в один клик и ежедневные автоматические.

## Обновления

Установленная программа сама проверяет обновления при запуске (по кнопке «Позже» можно отложить, галочкой — отключить проверки). Если вышла новая версия, она предложит: скачать установщик, проверить его контрольную сумму SHA-256 и запустить обновление — с вашего явного согласия, ничего не устанавливается молча.

Обновиться можно и вручную: скачайте `InviterStudioSetup.exe` из [последнего релиза](https://github.com/SalazarUltra/inviter-studio/releases/latest) при закрытой программе.

## Приватность и безопасность

- Данные, аккаунты и Telegram-сессии хранятся локально в `%LOCALAPPDATA%\InviterStudio` и никуда не отправляются.
- API-ключи и пароли прокси дополнительно шифруются средствами Windows (DPAPI) для вашего пользователя.
- AI-функции подключаются только если вы сами добавите ключ провайдера; без него всё работает на локальных шаблонах.
- Ведите учёт того, кому передаёте файлы сессий: `sessions\*.session` дают доступ к аккаунту. При передаче программы другому человеку достаточно одного установщика.

## Поддержать проект

Программа бесплатная. Если хотите поддержать разработку — кнопка «Поддержать проект» в программе (USDT/ETH, BNB — адреса и сети указаны в окне). Добровольно и без обязательств.

## Для разработчиков

Python 3.11+ (рекомендуется 3.14), Telethon, CustomTkinter, aiosqlite.

```powershell
py -3.14 -m venv .venv
.venv\Scripts\python.exe -m pip install -r requirements-lock.txt
.\start.bat                                  # запуск из исходников
.venv\Scripts\python.exe -m unittest discover -s tests -t .   # тесты (без сети и Telegram)
.\build.bat                                  # проверки качества + сборка установщика
```

Проверки (Ruff, тесты, сборка) автоматически запускаются на каждый коммит.
